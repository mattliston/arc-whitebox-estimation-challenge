# Final-layer cuts help only where third-cumulant sensitivity vanishes; retained contractions must be exact

2026-10-19T10:47:01Z · lesson · informational · derived

Because the relative error of the final variance prediction tracks the relative error of its k3 contraction, the k3 push at the final layer must stay exact to well under 1%; the only cheap final-layer cut is the row cut, which works because rows with |mu/sigma| > 3 have no k3 sensitivity (the terminal mean's k3 coefficient is -z phi(z)/(6v), zero at the kink and beyond |z| of about 3).

Recorded measurement:

    pair cut k3 error ~5% -> raw +5.56%; 85% would still cost ~+2.5%
