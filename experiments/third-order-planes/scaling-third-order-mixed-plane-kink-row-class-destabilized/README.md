# Scaling the third-order mixed plane by kink-row class destabilized final error

2026-10-17T18:40:59Z · experiment · rejected · measured

The off-diagonal third-order mixed plane was scaled by whether rows lay near a ReLU kink at layers 7–14. Large error increases and roster changes showed that its norm participates in covariance cancellations and cannot be adjusted independently.
