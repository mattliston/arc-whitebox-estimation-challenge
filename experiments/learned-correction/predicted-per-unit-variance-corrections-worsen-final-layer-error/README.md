# Predicted per-unit variance corrections worsen final-layer error by 1.2–5.3%

2026-10-01T20:40Z · experiment · rejected · measured

Leave-one-network-out ridge and boosting on the learned net's 30 inputs plus its 64-number state explain 9-20% of the card's per-unit variance error at layers 5-15. Feeding the corrected variance to the mean formula on network 35 with the learned mean correction on made the final error worse (truth variance would give -31.6%); with the correction off it helps 1.6-5.0%. The predictable part of the variance error is the information the learned mean correction already uses; no per-unit head adds anything.

Recorded measurement:

    explained share 9-20% (layers 5-15); closed loop learned on: boosting +4.9%, half strength +1.2%, ridge +5.3%, truth variance -31.6%; learned off: -1.6% / -1.7% / -5.0%, truth -26.5%; variance error rms 0.03% (layer 4) to 0.18% (layer 15), truth noise 0.018%
