# Reducing recentering strength below 0.92 worsens held-out error

2026-10-01T19:35Z · experiment · rejected · measured

The card shifts its covariance by -kappa (host d' + d host' + d d') after the learned mean correction d, with kappa 0.92. The covariance data say about 85% of that shift is wrong (regression slope of the cross vector on d -0.75 to -0.83), yet lowering kappa made the final error worse on 8 validation networks even though network 35 alone had shown -1%. No free gain; the dial stays.

Recorded measurement:

    kappa 0.7 / 0.5 / 0.3: +0.12% / +0.66% / +1.54% (8 validation nets); network 35 alone -1%; slope of cross vector on d -0.75 to -0.83
