# Joint retuning of the unchanged closure worsens forty-network raw error by 2.1%

2026-09-23T00:04Z · experiment · rejected · measured

Retraining every learned group of the deployed card without any structural change made validation worse after one epoch while the training loss stayed flat, so the deployed closure sits at its optimum and offers no free co-adaptation slack.

Recorded measurement:
