# Public networks cannot be regenerated: no seed in 0-300,000 matches network 0

2026-10-13T00:04Z · finding · informational · measured

The benchmark draws the public networks from SeedSequence(spec seed) and names them from its third substream; no spec seed in 0-300,000 or the usual round numbers reproduces the name of public network 0, so weight features had to be taken on 94 generated networks instead, and the staged learned ON / OFF test on the weak public networks 15 / 40 / 16 / 14 was cancelled (the observer-store ranks are a different set).

Recorded measurement:

    no spec seed in 0-300,000 gives 'natasha-heath' for network 0; 16 staged requests archived, never queued
