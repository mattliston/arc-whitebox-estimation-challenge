# Signed-pair third-cumulant rewriting keeps two full-width products; no dominant product removed

2026-09-08T09:01Z · finding · rejected · derived

Writing the paired factor columns P, Q as H = (P+Q)/2 and D = P-Q gives the exact plane K21 = [lambda (H^2 + D^2/4)] D^T + [2 lambda H D] H^T and k3_i = sum_r lambda_r (3 H_ir^2 D_ir + D_ir^3/4), but the two K-wide products have the same total contraction width as the original 2K-wide product, the plane is directed (the second term is not the transpose of the first) and marginal cube reads still need all rows. The older gated suffixes still restore 225 conventional push equivalents and the current all-P readers 240, so no exact sharing circuit was found.
