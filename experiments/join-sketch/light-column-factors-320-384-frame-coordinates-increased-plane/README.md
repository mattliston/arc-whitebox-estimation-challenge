# Light-column factors on 320 of 384 frame coordinates increased plane error by 33%

2026-10-18T02:09:31Z · experiment · rejected · measured

Reducing frame coordinates for light-column factors tested whether their contribution was concentrated in fewer directions. Even 320 of 384 coordinates increased plane error substantially, so the reduction was rejected.
