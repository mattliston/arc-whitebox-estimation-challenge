# Timing scope

The copied ordinary NumPy-free client executes module loading inside its first
prediction budget, then constructs the estimator and calls predict. The
installed SDK loads the module before timing predict. Consequently these cold
wall and residual measurements include extra setup and are conservative local
release checks. They are not a measurement of the platform's exact prediction
residual and do not establish a causal timeout repair or speedup.

Both sides of every new pair are packed estimators and use this same client.
The only semantic difference is65 final readout values. No residual reduction
relative to the unpacked ancestor is required or claimed. Complete cold/warm
operation counts and all16 output bytes must match their own qualified native
references. The existing SDK timing analysis is preserved at
../readout_residual_runtime_v1/SDK_TIMING_SCOPE.md.
