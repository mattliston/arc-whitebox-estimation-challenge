# Radial fourth-cumulant double insertion

Phase 2, 2026-09-19. A fixed new physical-map test on Weight5. No fit,
new dataset, sampling, or upload is part of this round. Preserve the old
L3-squared matched-fit negative; this is a different operator, L4-squared.

The current radial state has Q_ijkl = r(C_ij C_kl + C_ik C_jl +
C_il C_jk)/3. Thus its density insertion is L4 = r Delta_C^2/24,
and the selected extra term is L4^2/2 = r^2 Delta_C^4/1152. This is
an eighth derivative generated by the fourth cumulant, not a new eighth
cumulant or an assertion that all second-order Edgeworth terms are present.
L3-squared and L3 L4 are not added. No coefficient is fitted or damped.

For each normalized pair, Delta_C = d_x^2 + 2 rho d_x d_y + d_y^2.
Expand its fourth power and the Gaussian Mehler expectation, retaining
total correlation degree at most two, matching the parent's Edgeworth
correlation order. There are 26 raw derivative allocations. Remove the
two disconnected eighth derivatives and subtract twice F4 G4 inside the
common r^2/1152 factor; this is the product of the two first-order
marginal corrections. The resulting additions are cov(f,g), cov(f^2,g)
and cov(f^2,g^2), in the parent's three-channel convention. Use the
parent's existing central-moment assembly after these additions.

The marginal raw moment correction for power p=1..4 is
s^p r^2 p! A_(9-p)/1152, where A_k is the normalized kth derivative of
the Gaussian ReLU mean. Update all four raw moments and hence every
derived variance/skew/kurtosis and scalar final feature consistently.
The first, exactly Gaussian layer remains the original specialized map.
All heads, births, masks, tensor carriers and matrix kernels are unchanged.
Bulk pair additions use FP32, marginals use FP64, as in the parent.
No claim of a complete new third/fourth tensor source is made.

Before network execution, qualify the exact coefficients independently
against the bivariate moment-cumulant recurrence as formal polynomials in
r and rho; compare the r^2 coefficient of a polynomial covariance through
rho degree two. Verify scalar Hermite derivatives, zero-r recovery,
pair symmetry and finite synthetic map outputs. FP32 pair relative error
must be <=2e-5, exact coefficient identities must agree, and marginal
relative error must be <=1e-12. Failed identities stop network execution.

Then run native 35/100/35 and an independently cold 100. Seal all outputs,
hashes and complete own bills before opening the fixed existing 1B final
means. Compare against the authenticated Weight5 outputs, with a cold bill
on each network. Require first-layer exact equality, own repeat equality,
cold/warm equality, finite nonnegative outputs, both adjusted scores below
parent and pooled adjusted ratio <=.99. J is each raw MSE times
max(.1, complete own FLOPs / 2^41). These are development networks already
used in research, not fresh validation. A failure closes this fixed term:
no coefficient, correlation order, layer window, fit or precision sweep.
A pass warrants separate wider validation, not an immediate upload.

One numerical process group at a time, nice10, all BLAS threads1, existing
8GB RSS guard, <=256MiB additional swap, bounded wall time. Keep all owned
groups retired between stages. No existing artifact is overwritten.
