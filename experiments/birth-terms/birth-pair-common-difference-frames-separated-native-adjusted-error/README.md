# Birth-pair common and difference frames separated: native adjusted error rises

2026-09-26 · experiment · rejected · measured

Separate frames were used for the common and difference parts of birth pairs. Smaller common frames reduced some arithmetic but increased error, despite passing materialized, lazy and weighted-read algebra checks.

Recorded measurement:

    Four-network raw penalties +0.806% / +2.260%; native 384/256/192 common ranks versus submission #332361: adjusted +3.313% / +0.930%.
