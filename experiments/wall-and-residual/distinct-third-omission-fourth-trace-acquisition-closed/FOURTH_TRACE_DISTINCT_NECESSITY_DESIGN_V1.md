# Is the expensive distinct-third contribution necessary for the fourth core?

2026-09-06, Phase 2 only. Input-only representation diagnostic, not an
accuracy experiment, fit, or reopening of the cost-rejected full carrier.

The full augmented fourth partial trace was algebraically certified, but
its complete carrier failed an optimistic cost screen. The thin q4/s4
replacement failed a different gate because it approximated covariance
edges. Here retain ALL covariance edges and the full n-by-n fourth core.
Omit exactly the contribution returned by FullEdgeThird.fourth_third_part:
the input three-distinct-index third-cumulant block in the augmented trace.
All repeated third planes, Gaussian/heavy paths, fourth inputs, repeated
corrections, and post-covariance centering remain unchanged. This is one
specified source-class omission, not a rank or edge truncation sweep.

Hypothesis: that expensive n-squared-times-CP-rank contribution might be
small AFTER removal of the existing radial fourth trace. If so, a cheaper
full-matrix core acquisition deserves further cost/physics analysis. No
assumption is made that the remaining fourth-to-third carry is affordable.

## Before the wide calculation

explicit omitted contribution, to 1e-10 absolute. Independently certify
the full-rank covariance-metric core inverse: for Q=Sym(A,C),

    R = (trace(C)*A + trace(A)*C + 2*(C@A+A@C))/6.

In C's eigenbasis, off-diagonal A_ij = 6*R_ij/(trace(C)+2*(lambda_i+lambda_j));
the diagonal is solved with the single trace(A) consistency equation.
This full eigensolve is an OFFLINE diagnostic, not a deployment proposal.

Use exactly current bank rank35, pre/post layer12. Run rank100 at that
same cell ONLY if35 passes. No new samples or targets. Reproduce prefix
features/sigmas byte-exactly against the existing current bank tapes.
The detailed pair map must reproduce the actual current m/C/K21 target
and radial output byte-exactly before attribution.

Use the ACTUAL current masked K21 for every pair map, repeated correction,
and lower-support path. Thus the diagnostic tensor's repeated entries are

explicitly symmetrized; record its asymmetry and core reconstruction error.

radial trace before judging relative errors. Require <=0.10 relative error
for each of:

1. full anisotropic trace matrix;
2. covariance-metric anisotropic core matrix;
3. next-layer scalar fourth mean response f*k4/24 after the actual W13;
