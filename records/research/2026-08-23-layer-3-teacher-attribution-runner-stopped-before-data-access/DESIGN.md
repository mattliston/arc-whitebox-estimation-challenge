# Phase 2 teacher attribution and data program

Status: **DESIGN/AUDIT ONLY — NOT LAUNCHED**  
Shape: width 1024, depth 16  
Objective: determine the smallest correction that can plausibly push final-layer
raw MSE below `1e-7`, before spending time on an observer.

This design pass decoded no public target value, fit no model, generated no
teacher sample, and did not inspect an official example. It reuses mathematical
and experimental lessons from Phase 1, but no Phase 1 checkpoint, rank, fitted
constant, normalization, or numeric calibration.

## Recommendation

Build one independent, high-fidelity teacher tape on a small **network-disjoint
Phase 2 cohort**, then run a five-arm scalar substitution ladder and two
one-step action tests. Do not start by imitating a teacher's hidden state.

The main training target, if training is licensed later, is the public
all-layer post-ReLU mean residual along the deployable host's own autonomous
16-layer rollout. Teacher moments are auxiliary labels that say *why* the mean
is wrong. This directly avoids the Phase 1 failure in which a model imitated
isolated teacher states but drifted when its own corrections changed the next
state.

## Exactly which teacher quantities to make

For each selected network, let `z_l` be the pre-ReLU vector and `h_l` the
post-ReLU vector. All sampled moments use an offline Gaussian input bank that
is independent of the organizer's public mean bake.

| Quantity | Shape per layer | Purpose | Scope |
|---|---:|---|---|
| post mean `E[h_l]` | `1024` | Main mean label and final score target | Use the public `all_layer_means` only after the split-specific target gate opens |
| causal pre-mean `E[z_l]` | `1024` | Tests mean-state drift | Compute from the independent teacher bank; retain public previous-mean `@ W_l` only as a separately marked high-precision control |
| pre variance | `1024` | Scalar ReLU scale and diagonal transport | All teacher cohorts |
| post covariance `Cov(h_l)` | symmetric `1024x1024` | Exact second-order transition/action authority | Full matrix on the 24-network attribution cohort only |
| pre K3 | `1024` | Scalar skew correction | All teacher cohorts; it is the diagonal of K21 |
| pre K21 | `1024x1024` | Pair consumer and hidden-third-order action diagnosis | Full plane on 24 attribution networks; fixed rank-32 projections at training scale |
| pre K4 | `1024` | Conditional scalar tail/readout diagnosis | Diagonal only; never pretend this is a recursive fourth-order state |
| autonomous host features | about 32 local channels | Inputs actually available at deployment | Generated by the frozen Phase 2 host, never by teacher forcing |

The K21 convention is fixed as
`K21[i,j] = E[(z_i-E[z_i])^2 (z_j-E[z_j])]`; it is not symmetric and its
diagonal must equal K3. A visible K21 plane is **not** a complete recursive
third-order state: dense mixing also rotates all-distinct triples into future
K21. For that reason, the tape additionally stores the directly sampled next
pre-K21 action (or `K21 @ R` at scale) instead of manufacturing a fictitious
full tensor from K21.

The rank-32 probe matrix is one target-independent orthonormal signed matrix
derived from `SHA256("p2-teacher-v1|probe32")` and frozen across every split.
It is not fitted to a residual or changed after a target opening.

Post covariance is sampled directly. The next pre-covariance is derived as
`W.T @ Cov(h) @ W`, which is much cheaper and more accurate than sampling a
second dense matrix. K4 is stored as the diagonal fourth cumulant and in a
standardized Hermite-4 form to reduce near-Gaussian cancellation.

## Small bottleneck-localization program

### 1. Five-arm same-layer scalar substitution ladder

Run the following cumulative arms with one frozen scalar mean readout and one
frozen autonomous host. Each arm replaces fields only in the current layer's
scalar readout; it does not feed that teacher field into the next layer.
Teacher fields come from the independent teacher bank; public means are used
only as evaluation labels.

The separately reported public previous-mean `@ W_l` control is not allowed to
decide the `1e-7` gate: adjacent-layer public means were baked from the same
Gaussian draws, so that control shares sampling noise with the output label.

1. `S0 autonomous`: no substitution.
2. `S1 + causal mean`: replace current pre-mean only.
3. `S2 + variance`: additionally replace the pre-variance.
4. `S3 + K3`: additionally replace marginal pre-K3.
5. `S4 + K4`: additionally supply diagonal pre-K4.

Report final-layer and all-layer raw MSE, the complete 16-layer curve, and
paired network-level gains for every adjacent step. Full covariance is
deliberately absent: once a neuron's marginal variance is fixed, off-diagonal
covariance cannot change that neuron's same-layer ReLU mean. S4 is the
low-order scalar ceiling. If S4 is below `1e-7`, the information is sufficient
and the job is to learn/transport the missing coordinates. If S4 remains above
`1e-7`, do one separately preregistered cross-fit readout-capacity probe before adding a
recursive observer; success would implicate the readout map, while failure
would implicate missing distributional information such as higher tails.

Exact substitutions can remove a compensating error. Therefore no adverse
single step closes a field by itself. Interpret the cumulative tower together
with S4. For any adverse or ambiguous step, permit exactly one predeclared
leave-one-out comparison from S4; do not sweep mixtures or damping values.

### 2. Covariance one-step action test

At every source layer, compare the host post-covariance with teacher
`Cov(h_l)`, propagate each through the real next weight, and measure error in:

- next pre-variance;
- fixed rank-32 covariance probes; and
- the next-layer mean after the unchanged scalar readout.

This separates a bad scalar variance from bad off-diagonal covariance
transport without recursively teacher-forcing the whole trajectory.

### 3. K21/third-order one-step action test

Measure two different failures rather than conflating them:

- **consumer error:** give the existing bivariate ReLU consumer the true
  current K3/K21 and measure its post-covariance and next-variance action;
- **carrier error:** compare the host's next pre-K21 with directly sampled
  next pre-K21, including fixed rank-32 actions.

Only a material, noise-certified downstream mean action licenses more tensor
capacity. K21 is not inserted as a standalone recursive state.

## Cohorts and leakage discipline

Use the pinned official dataset
`aicrowd/arc-whestbench-public-2026@v2-phase2`, not a Phase 1 Keenan dataset.
The `mini` and `full` networks are disjoint. Mini remains a development record;
the fresh teacher program uses `full`.

Before reading any full target, sort all 1,000 full rows by
`SHA256("p2-teacher-v1|v2-phase2|" + decimal_mlp_seed)` and freeze these exact
network-level partitions:

- positions `0:700`: fit;
- `700:800`: selection;
- `800:900`: audit;
- `900:1000`: final public lockbox.

The attribution cohort is the first 12 hashed fit networks plus the first 12
hashed selection networks. The first 128 fit and first 32 selection networks
form the optional high-moment training tape. No neuron or layer from one
network may cross a network split. Losses and confidence intervals cluster by
network, not by the millions of correlated neuron-layer rows.

The sampler must physically project only `mlp_id`, `mlp_name`, `mlp_seed`, and
`weights`, following `data_gate/target_blind_mini.py`. A separate process may
join public means for the authorized fit/selection rows after every sampler,
host, split, and prediction hash is sealed. Audit and lockbox targets remain
unread until their one-use gates. The public output labels and offline teacher
feature samples must never use the same Gaussian draws; otherwise same-sample
control-variate correlation can masquerade as estimator accuracy.
`avg_variance` is a post-score noise diagnostic only, and neither it nor
`sampling_budget_breakdown` may become an estimator feature.

## RQMC/Monte Carlo protocol and error certificate

Use eight independently Owen-scrambled Sobol replicates, base-2 sample counts,
and seeds derived only from the dataset revision, `mlp_seed`, replicate index,
and the literal `p2-teacher-v1`. Do not use any target, residual, or score in a
sampling seed. Forward propagation is float32, matching the published bake;
moment merges and normalizations are float64 on CPU.

Start at total `N=2^18` samples per network (`8 x 2^15`). Escalate the same
nested sequences to `2^20`, then at most `2^22`, based only on uncertainty—not
on which arm wins. Each replicate independently produces every ladder arm.

The operational certificate is:

1. split the eight replicates into two fixed four-scramble banks;
2. for every arm, require the 99% network-clustered upper bound on one half of
   the two-bank prediction disagreement MSE to be at most `1e-9` at the final
   layer (one percent of the `1e-7` decision scale);
3. require the sign and `1e-7` crossing classification of every material
   adjacent gain to agree at the last two sample levels;
4. require the 12-network confirmation half to reproduce the selected
   bottleneck direction; and
5. after target opening, report the published reference-noise diagnostic
   `avg_variance / 1e9` rather than treating the public mean as exact.

This is an empirical replicated-RQMC certificate, not a formal tail theorem.
If it fails at `2^22`, the corresponding teacher conclusion is blocked. Do
not silently use a noisy K4 or K21 label.

Layer 1 supplies an exact control: its preactivation is Gaussian, so pre-K3
and pre-K4 are zero and its covariance and ReLU mean are available directly
from `W_1`. Every device and accumulation path must pass that control.

## MPS acceleration and CPU authority

The current machine has a 40-core Apple M3 Max with Metal support. An
unsandboxed check found PyTorch `2.7.0` with MPS built and available. MPS does
not support float64, so it is an accelerator, not the numerical authority.

- MPS may perform float32 network forwards and, after parity, centered dense
  matrix products.
- CPU float64 performs blockwise moment merging, standardization, hashes, and
  the authoritative small replay.
- Before public extraction, replay two synthetic networks and then two
  target-blind public-weight networks with identical saved inputs on CPU and
  MPS. Require induced ladder-prediction device disagreement MSE `<=1e-10`,
  every diagonal-moment discrepancy below 10% of its cross-scramble standard
  error, K21-diagonal/K3 agreement, covariance symmetry/PSD checks, and exact
  finite shapes.
- Require two identical MPS reruns and at least `1.5x` end-to-end speedup after
  transfers. Otherwise retain MPS for observer training only and generate
  teacher authority on CPU.

No MPS operation appears in submitted `predict()` merely because it was used
offline.

## What a later learned estimator should consume

Do not make teacher hidden states the primary examples. For each fit network,
roll the deployable host autonomously for all 16 layers and store its local
features. Main labels are public post-mean residuals. Optional auxiliary
labels are residuals in causal mean, log-variance, standardized K3/K4,
covariance-probe actions, and K21-probe actions.

Train a shared 16-step residual observer through its complete autonomous
rollout. Select by network-balanced held-out final-layer MSE, with a smaller
all-layer stability term. Begin readout-only so an imperfect correction cannot
destabilize the analytic carrier. Feedback is licensed only if the substitution
and action tests show that carried-state drift, rather than readout error, is
the floor; any feedback model must then be trained on its own state
distribution end to end.

The optional data scale is deliberately asymmetric:

- all 700 fit networks can provide cheap mean-residual examples;
- only 128 fit plus 32 selection networks need rank-32 higher-moment/action
  teachers initially;
- full dense covariance/K21 stays confined to the 24-network attribution
  cohort.

The full count is one network forward plus one post-covariance and one
pre-K21 matrix product per layer; diagonal K4 is lower order. Divide the FLOP
count by measured sustained device FLOPs/s for a wall-time estimate—no
unmeasured MPS speed is claimed here.

A compact float64 full-attribution record is about 197.7 MiB per network or
4.63 GiB for 24 networks, excluding already-cached 64 MiB weights. A rank-32 teacher
tape with 32 autonomous host channels is about 6.31 MiB per network or 0.99
GiB for 160. A 700-network mean-only tape is about 1.41 GiB.

The official full Parquet download is about 65.15 GiB, and Hugging Face may
materialize roughly another 65 GiB of Arrow data. Use direct projected
Parquet streaming or require at least 160 GiB free before launch.

## Explicit launch blockers

1. Freeze the exact Phase 2 baseline host and scalar readout hashes. The
   recursive CP/K21 candidate is not interchangeable with the open-loop host.
2. Materialize and hash the exact 1,000-row split manifest before target
   access; use the explicit Hugging Face config name `full` because the current
   sidecar/config metadata disagree.
3. Extend the physical target-blind Parquet projector and deny-list audit from
   mini to full.
4. Freeze the sampler, moment conventions, RQMC seed schedule, and five-arm
   runner before decoding any selected target.
5. Pass exact layer-1 controls, K21 orientation/diagonal tests, covariance
   symmetry/PSD tests, and the CPU/MPS parity gate.
6. Run the static disk/memory preflight and the measured MPS/CPU throughput
   pilot; no 24-network extraction begins without a resource receipt.
7. Obtain a separate root release to open only the 12 fit and 12 selection
   attribution targets. This document itself authorizes no opening.
8. Satisfy the replicated-RQMC noise certificate. Failure at `2^22` blocks the
   affected attribution rather than licensing a noisy conclusion.
9. Freeze the observer data interface and a result-contingent decision before
   any fit. No architecture sweep is chosen from attribution targets.
10. Keep audit/lockbox targets sealed, and do not access any official hidden
    evaluation example. Phase 2 submission also remains subject to the
    organizers' formal launch and final rules.
