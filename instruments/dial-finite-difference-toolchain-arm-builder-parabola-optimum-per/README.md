# Dial finite-difference toolchain: arm builder, parabola optimum per pair, truth-half split, release stack builder

2026-10-19T18:52:00Z · tool · adopted · measured

The dial campaign ran on a small toolchain: build_dial_fd_v2/v3 emit zero-bill finite-difference arms (34 dials: pair-law strengths and shapes, births, rows, scales, fourth-order birth theta/c, GK4, head ages, BFIX gamma, GSK, S19 parameters, BD j1); fd_parabola_v1 turns a +-step pair into slope, curvature, optimum and gain; fd_pair_asym_v1 re-reads pairs with asymmetric steps and a truth-half split; build_dial_stack_v1 and build_release_stack_v1 fold chosen optima (and optional k3/k4 shape or terminal-k3 terms) into a science copy or a release form on the fired physics.
