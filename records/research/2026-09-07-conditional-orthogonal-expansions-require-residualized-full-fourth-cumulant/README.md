# Conditional orthogonal expansions require a residualized full fourth-cumulant slice beyond repeated planes

2026-09-07 · finding · informational · derived

The second-order conditional projection identifies the missing full fourth-cumulant slice after subtracting the projected third-order term. Existing repeated-index planes do not determine this slice, and substituting the current factor model supplies only information already represented by that model.

Recorded measurement:

    E[epsilon_i epsilon_j|y]=R_ij+U_ij*y/v+(V_ij-(t/v)*U_ij)*P2(y)/N2+remainder;N2=0 is a degenerate basis case.
