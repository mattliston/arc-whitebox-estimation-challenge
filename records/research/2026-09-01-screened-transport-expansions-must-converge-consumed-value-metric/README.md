# Screened-transport expansions must converge in the consumed value metric

2026-09-01 · lesson · informational · measured

An exact screened-transport expansion improved tensor alignment while supplying essentially no endpoint value. Large opposing map-gap and return-transport contributions made the surviving correction sensitive to the accuracy of each term.

Recorded measurement:

    **Out-and-back expansion (2026-09-01): Frobenius-real, value-empty at
    k=1/d8.** The screened-transport expansion verified exact (unit-β,
    corr→0.45 vs full−kt) yet carried ~0 consumption value pure (0.2%)
    and inherited kt's −63% transfer when glued. LAW REFINED: check
    VALUE-metric convergence, not Frobenius, before investing in any
    expansion's higher terms. Assets kept: the factored motif algebra +
    small-n harness (c4v2_smalln_harness.py) + the C1 adjoint grader.
    
    **TERMINAL CONSTANT (2026-09-01): the 5.8:−4.8:1 cancellation.** The
    chain's consumed value = the residue of map-gap (+124, 5.8×) vs
    out-and-back (−102.5, −4.8×) through the C1 adjoint (r35). Assembling
    the pair needs ±3.5% value-accuracy each side — unreachable by
    term-wise expansion (measured ~0). EVERY approximation method this
    month died on this one structure. Viable successor = residue-basis
    reformulation only (diagonalize the screening; SOL's Jordan-quotient
    target). Receipt: public_g19_attribution_v1/valdecomp.py.
