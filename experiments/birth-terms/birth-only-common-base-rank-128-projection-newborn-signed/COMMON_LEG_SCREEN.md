# A distinct common-leg compression screen

The scalar-final component is useful only at small scale. The remaining
large bill is the cubic carrier. This screen tests a necessary accuracy
condition for a different representation of its young sources; it is not a
priced or deployable estimator and will never be submitted as written.

A newborn signed pair has columns B[:,j]+t_j e_j and B[:,j]+s_j e_j,
with equal opposite coefficients. Earlier whole-pair projection loses the
coordinate difference leg. The September 5 difference-leg proposal instead
kept the common leg dense and compressed the difference. Both are preserved.
Here ONLY the common base is projected at birth. The coordinate difference
is preserved exactly, and the repeated plane change is absorbed in the same
existing star reset. Thus this is neither old-pair confinement nor a change
to the gate/birth threshold.

Selected pilot: births4..14 only, rank128, no rank/age sweep. Complete the
zero diagonal of the selected base with g_i*v_i on alive units before a
truncated SVD. This avoids spending rank on the artificial removal of the
diagonal. Remove the projected diagonal afterward. In a future factored
implementation, if Bhat=U*V-diag(d), the diagonal removal is represented
exactly by t'=t-d and s'=s-d. The subsequent direction leg remains dense.

For a change D=Bhat-B, the signed pairs' off-diagonal repeated-plane change
is (2*B*D+D*D)*[a*(t-s)] by column, plus [a*(t*t-s*s)] by row times D.T.
Its diagonal is zero because the zero-diagonal bases leave each self entry
unchanged. Add this to the current BD plane delta before the current star
reset. Masks and all learned parameters stay fixed.

The pilot uses an offline NumPy SVD to measure accuracy only on rank35 and
rank100, serially after the paired panel. NumPy cost is deliberately NOT
called a participant bill. It saves full outputs before examining the 1e9
references. A large accuracy loss rejects this fixed proposal without a
carrier rewrite. A small loss merely permits a complete cost derivation and
a deployable basis-acquisition test; it does not prove a bank.

Potential circuit: keep U and V fixed within a cohort except for transporting
U; transport the full coordinate leg separately; reconstruct both signed
columns for the existing readers and old-tier ingress. At n1024 and rank128,
the common transport plus reconstruction replaces one n-by-n push with two
rank128 products. Read costs, old-tier costs, masks, storage, construction,
and diagonal shifts remain. The young-push bill is 31% of I95, so even an
optimistic 37.5% cut there is only 11.6% of total BEFORE basis construction
and implementation overhead. No 2x saving or raw improvement is forecast.
