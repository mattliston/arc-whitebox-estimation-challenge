# Stable training reference combines late classical products and float64 Nyström sketches

2026-09-27 · tool · informational · measured

The fitting reference used late ordinary products plus float64 sketches and QR at joins10 and13, returning bases to float32. It qualified sampled final responses but was too costly to deploy unchanged, so any fitted correction still required transfer to the original fast estimator.
