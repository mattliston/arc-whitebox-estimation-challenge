# A row-sum and diagonal representation preserves most of the fourth-cumulant read direction

2026-10-01T00:58Z · finding · informational · measured

A symmetric fourth-cumulant matrix is approximated as u1ᵀ+1uᵀ+c11ᵀ+diag(v), with u, c and v chosen to preserve its row sums and diagonal exactly. This permits the next-layer per-unit contraction using vector carries instead of the full matrix. Passive full-depth comparisons on two networks pass the preset fidelity thresholds while preserving every parent prediction byte and charge; this is a direction-fidelity result, not an accuracy gain.

Recorded measurement:

    networks 35/100; relative squared read errors 0.118811/0.125461; centered correlations 0.934133/0.930587; scalar-mean-weighted relative squared errors 0.048731/0.049154; 12 algebra cases, maximum error 1.05e-11
