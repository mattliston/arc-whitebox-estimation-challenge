# Rank-one fourth-cumulant leaf plane needs one dense product

2026-08-31 · finding · informational · derived

For leaf plane P=uu^T, the exact fourth-cumulant two-pair plane (K22) action collapses to H=R Diag(u) W^T plus O(n^2) reductions. This is a source-factor identity, not a statement that the physical P-sharp plane is rank one.
