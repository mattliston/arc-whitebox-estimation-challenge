# Local network rank is a salted hash order and provides no demonstrated difficulty ordering

2026-09-30 · finding · informational · measured

An audit verified that local observer rank was derived from a salted seed hash rather than generation order or difficulty. The observed small-panel reversals were not evidence that higher rank meant harder networks.
