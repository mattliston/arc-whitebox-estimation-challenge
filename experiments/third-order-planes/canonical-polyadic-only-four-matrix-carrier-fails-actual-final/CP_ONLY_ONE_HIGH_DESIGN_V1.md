# CP-only one-high matrix carrier, explicit star and trace retained

September 5, 2026, Phase 2. New state boundary and birth compiler.

The earlier one-high static test compressed CP AND coordinate-star
together and stopped on26.8% relative next-skew change, before recursive
means. That receipt remains intact. This test replaces only the Gaussian
paired-birth CP bank; the full coordinate-star and trace tensor remain
separate and their existing semantics are preserved. This is not a
rank/strength sweep of the closed whole-tensor comparison.

Represent the CP sector as T=Sym3(sum_a U_a L_a), q=4. Four symmetric
matrices, no historic factor bank. Push U and L linearly; compute the full
pre repeated plane and all diagonal scalar reads. Reproject inherited CP
plus newborn CP at each layer. The coordinate star is rebuilt from the
same nonlinear target minus projected CP and trace, so its complete
repeated plane remains represented. Do not carry its discarded distinct
linear part or add positive-path physics in this baseline prototype.

The new paired birth tensor has an EXACT cheap slice compiler:
Sym3(sum_c birth_c e_c B_c B_c) plus the coordinate tensor determined by
birth*u and the existing diagonal innovation. This needs one dense
matrix product per query, not two separate paired-cube products.

Use four fixed power/QR iterations for the current active covariance
subspace, initialized by the pushed previous basis; initially the first
four coordinate vectors pushed through W0. No truth-derived basis,
eigenspace rank sweep, alternate iteration count or layer schedule.
Features are still captured before the current mean correction. The
updated covariance basis is state for FUTURE layers only.

First small dense certificates: one-high tensor/plane algebra, arbitrary
linear transport, complete paired-cube birth slices and exact coordinate
restoration. Then complete source-blind arithmetic opportunity pricing,
including pushes, basis, source, read and star/trace/covariance costs.
Large products may use the already-qualified f32 bank kernel schedule;
all required dtype conversions and elementwise work must be counted.

Require at least25% projected whole-bank savings before a fixed two-net
actual NumPy closed-loop check (35/100,1e9 truths). Compare unlearned and
unchanged bank readouts, not only tensor self-error. Only if frozen-head
raw increase is <=15% on BOTH nets, and predicted adjusted improves >=15%
on BOTH, design a matched pilot. Otherwise close without rank/iteration/
strength/epoch sweeps. No submission without the complete release gates.
