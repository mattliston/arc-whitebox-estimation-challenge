# Variance-error attribution localized the missing signal to off-diagonal covariance transport

2026-09-04 · finding · informational · measured

VARIANCE ERROR IS OFF-DIAGONAL-BORN (r35, oracle recursion, 32M truth): the pre-variance error at L12/L14/L15 (0.56/0.78/0.85% rel rms) is explained only 3-4% by the previous layer's per-unit POST-VARIANCE errors pushed through W^2; 96-97% comes from the OFF-DIAGONAL post-covariance error at l-1 pushed bilinearly (diag(W^T dC W)). With T-100 (the covariance residual is low-rank and mean-aligned, dC ~ a m^T + m a^T) this gives dv_l,i ~ 2 pre_m_l,i (W^T a)_i: a per-unit vector a at l-1 pushed through W times the pre-mean - representable by the message channel + encoder products, which the interior evidently learns. PRIORITY CALL: the final-layer deficit (6.4e-9) is a PODIUM problem; the BAR (adjusted < 1e-8) needs only the loop control - compute goes to control first.
