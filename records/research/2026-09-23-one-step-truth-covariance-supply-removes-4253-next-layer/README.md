# One-step truth-covariance supply removes 42–53% of next-layer variance error

2026-09-23T02:28Z · finding · informational · measured

A 32M-sample second-order Monte Carlo truth factory (layers 4/7/10/13, A/B halves) and a one-step budget on network 100 attribute the next-layer variance error of the card mostly to the carried covariance, then the K21 off-diagonal; a bug in the original script (swapped mix() arguments) was found and a fixed copy shows truth k3+k4 move the next variance 0% and the mean -5..-9%.

Recorded measurement:

    v_{l+1} card .073/.112/.158% (L7/10/13) -> truth C .042/.057/.074% (-42..-53%); truth K21off -10..-12%; truth K31 -1..-2%; post-mean card 1.14-1.37e-4 -> truth mu 5.3-6.6e-5; fixed copy: truth k3+k4 -> vnext 0%, mean -5..-9%
