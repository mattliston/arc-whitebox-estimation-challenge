# Folding all births into one frame at layer 8: raw error 1.51x at rank 768 and 16x at rank 384

2026-09-24T17:25Z · experiment · rejected · measured

Early folding failed the score gate before any refit. The larger frame increased work while the smaller frame lost too much information.

Recorded measurement:

    - 2026-09-24 10:25 [physicist] FOLD-AT-BIRTH TEST (refit6b/foldpush.py + refit_s6b_fold.py; torch S6b + B2 ep1 literals; every3 control bit-exact): no-refit VALID16 vs B2 ep1 1.74614e-8: fold8 r=768 2.636e-8 (+51%, 0/16 better), fold8 r=384 2.833e-7 (16x). Bill (fold_bill.py, S2 census-calibrated, dense-product units/layer vs 11.83): r=768 15.41 (+30%; layers 8-15 13.9 -> 21.1), r=384 10.65 (-10%). Cannot pass (adj <= -15%) at any rank -> refit NOT started (offered to the lead for learnability only). Lesson: bill = columns x per-column cost (~2*1024*r + 2*resp*r); a lean card needs FEWER columns, not a fold.
