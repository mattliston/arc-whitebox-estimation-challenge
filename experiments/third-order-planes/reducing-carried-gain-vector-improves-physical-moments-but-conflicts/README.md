# Reducing the carried gain vector improves physical moments but conflicts with learned corrections

2026-09-24T22:21Z · experiment · inconclusive · measured

Scaling the vector by 0.9 improved plane and per-unit third-cumulant errors and the learned-off estimator. Learned-on error worsened, motivating a refit rather than direct adoption.

Recorded measurement:

    - 2026-09-24 15:21 [physicist] b-scale learned-OFF VALID16 vs learned-off control: b x0.9 0.9729 (13/16), b x0.8 0.9970 (8/16). Physics is right, co-adaptation blocks it at no refit (learned on, r35: +5.3%). Refit candidate: B2 recipe with b x0.9 via the b_post hook, or a trainable b scale.
    - 2026-09-24 15:25 lead: PHYSICIST §K: the carried b channel's distinct content is 2.5-4x over-represented. Cutting b improves the kink planes (7.21/8.37 -> 6.32/7.17% at b x .9) and per-unit k3 (5.37/6.32 -> 4.64/4.91%). No-refit learned-ON the final MSE WORSENS (+5.3% at x.9; the learned parts cancel the excess b). Learned-OFF VALID16 b x .9 = -2.7% (13/16), x .8 = -0.3%.
