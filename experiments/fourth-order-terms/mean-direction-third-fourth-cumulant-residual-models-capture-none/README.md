# Mean-direction third- and fourth-cumulant residual models capture none of the oracle gain

2026-09-25T05:17Z · experiment · rejected · measured

A visible low-rank residual aligned with the mean, but even oracle-fitted scalar mean-direction models did not provide the useful per-unit correction.

Recorded measurement:

    - 2026-09-24 22:17 [physicist] k3/k4 SOURCE SCREENS (r35/r100, 32M truth, B2 ep1 card), for the research page. (1) The per-unit k3/k4 residual's low-rank part lies along the post MEAN direction (= top eigvec, |cos| .96-.97): mean-dir R^2 k4 .13-.21, k3 .08-.44, random controls .01-.04. But a mean-direction model (eta mu^3, zeta mu^4 per layer, in-sample oracle scalars) captures NONE of the lever: final MSE with delta 0.5 at L12-14 +1.9/+4.7% vs control +1.7/+4.9% (truth k3/k4: -16.8/-10.9%). (2) Previous-layer Gaussian-born tree k4 pushed per unit (star, path) explains R^2 .00-.04 of the k4 residual. So the lever is unit-specific (high-rank) and carried.
