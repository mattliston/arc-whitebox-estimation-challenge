# Exact fourth-order plane-slice residual leaves final error unchanged

2026-09-22T21:19Z · experiment · rejected · measured

Adding the exact residual of the (2,2) and (4) slices of the post-activation fourth-order plane, which the card collapses into a scalar radial, to the next layer's k4 changes neither the per-unit k4 error nor the off-diagonal K22 nor the final MSE; the per-unit k4 structure lives in the (3,1), (2,1,1) and (1,1,1,1) slices, whose Gaussian-born tree diagrams would cost ~4 units per layer.

Recorded measurement:

    k4 rel err 0.14-0.27 -> same (corr +0.003); K22 off-diagonal unchanged; apply-mode final 1.6499e-8 vs 1.6489e-8; tree diagrams ~4 units/layer (+2%/layer)
