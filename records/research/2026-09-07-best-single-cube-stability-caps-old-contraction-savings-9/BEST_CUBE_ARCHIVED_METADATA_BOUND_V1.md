## A useful bound without rejected-pair arrays

Let T=p^3-q^3, d=p-q, h=(p+q)/2. For d nonzero choose orthonormal axes along
d and h's perpendicular residual. After dividing out ||d||^3, write

    h/||d|| = gamma*e1 + x*e2, x >= 0,
    T111 = a = 3*gamma^2 + 1/4,
    T112 = b = 2*gamma*x,
    T122 = c = x^2,            T222 = 0.

Each repeated index denotes its symmetric orbit. Normalize by a>0 and put

    t = (b/a)^2,     s = c/a,     t <= 4*s/3,
    N = ||T/a||_F^2 = 1 + 3*t + 3*s^2.

The difference-axis first jet matches T111 and T112 exactly. Its squared
residual numerator J and the mode-one flattening Gram determinant P are

    J = 3*(s-t)^2 + t^3,
    P = 2*(s-t)^2 + t*s^2 + 2*s^4.

The family constraint gives t^3 <= (16/9)*t*s^2, hence J <= (16/9)*P.
If the relative best-cube error e is at most 0.1, the less constrained
rank-one matrix approximation to the flattening implies

    P/N^2 <= e^2*(1-e^2).

For an optimal unit cube direction v, its fitted amplitude has magnitude
sqrt(1-e^2)*sqrt(N). Because T222 is zero,

    |v2|^2 <= (e^2/(1-e^2))^(1/3) < 0.217,
    |v1|^3 > 0.783*0.884 = 0.692172.

The 111 component, allowing its full residual norm, therefore gives

    1 > (0.994*0.692172 - 0.1)*sqrt(N) > 0.588*sqrt(N).

It follows that

    e_jet^2 = J/N <= (16/9)*e^2*(1-e^2)*N,
    e_jet < (4/3)*0.1/0.588 = 100/441 < 0.23.

Root and the accuracy agent independently checked the proof. The metadata
calculator verifies all conservative decimal inequalities with exact
rational arithmetic. Zero differences/zero external weights have zero
tensor and zero error by convention; collinear pairs are exact one-cube
cases. A common signed external weight leaves relative errors unchanged.
The result is exact algebra, not an endpoint-error or machine-rounding bound.

## Restoration is two columns in real arithmetic

An optimal unit direction lies in span(h,d). If v=u*h+w*d and its fitted
amplitude is k, the residual current repeated plane is

    (T-k*v^3)_21
      = [2*h*d-k*u*v^2]*h.T
        + [h^2+d^2/4-k*w*v^2]*d.T.

Products inside brackets are componentwise. Thus it needs two outer products
per pair, not three. Equivalently, absorbing amplitude into z=A*p+B*q,

    (p^3-q^3-z^3)_21 = (p^2-A*z^2)*p.T + (-q^2-B*z^2)*q.T.

If the stored vector is z32, the latter assembly misses
z32^2*(A*p+B*q-z32).T relative to the residual of the three stored cubes.
Stable near-degenerate coefficients, that FP32 discrepancy, padding and
propagated residual error need explicit qualification. A current plane
repair is not exact future tensor transport or free future truth.
