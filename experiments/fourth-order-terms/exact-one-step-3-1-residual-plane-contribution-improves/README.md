# Exact one-step (3,1) residual-plane contribution improves raw error but costs more arithmetic than it saves

2026-09-23T02:13Z · experiment · rejected · measured

The Gaussian-born star term of the (3,1) plane is physically right (joint-fit coefficient 0.86-1.08 against Monte Carlo truth) but explains only 1-2 points more of the true K31's variance than the isotropic form, and in closed loop it buys -1.45% raw for two n x n_sel x n reads per layer, so it does not pay.

Recorded measurement:

    star_k31_truthcheck: coefficient 0.86-1.08, R^2 iso .43-.55 -> both .44-.57, star rms 13-16% of truth; closed loop lam 1.0 from L2: mean ratio 0.9855 (35 .991, 100 .969, 37 .990, 39 .992), lam .5 0.9889; from L11: 0.9925 / 0.995; cost ~0.36% bill per layer
