# Covariance oracle in a mean-annihilating zero-diagonal subspace improves raw error 41.75%

2026-09-27 · finding · informational · measured

Privileged covariance reference inputs were decomposed into a mean-annihilating zero-diagonal subspace and its excluded complement. The useful subspace outperformed the full oracle on two reused networks; this is not a deployable gain.

Recorded measurement:

    MINI57/68:FULL raw-34.83%;PERP raw-41.75%;COMPLEMENT+5.37%.
