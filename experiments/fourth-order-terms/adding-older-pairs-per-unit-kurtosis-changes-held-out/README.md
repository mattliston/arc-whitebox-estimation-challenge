# Adding older pairs to per-unit kurtosis changes held-out error by less than 0.04%

2026-10-02T08:14Z · experiment · rejected · measured

On top of the per-unit kurtosis term at ages 1-2 (strength 0.75), adding the pairs of ages 3-4 at reduced weight is free natively (the pairs are young) but worth nothing on six held-out ranks: final layer only at relative weight 0.5 / 1.0 gives -0.04% / +0.04%, all layers at 0.3 / 0.6 gives -0.06% / +0.04% (layers 6-14 better by 0.3-0.6%, the final layer not).

Recorded measurement:

    final layer only 0.5: -0.04% (se 0.05), 1.0: +0.04% (se 0.10); all layers 0.3: -0.06% (se 0.08), 0.6: +0.04%
