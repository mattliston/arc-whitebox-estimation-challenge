# Exposure-trained two-auxiliary-state successor: measured and rejected

2026-08-24 · experiment · rejected · measured

The single preregistered 20-epoch successor adds two independently Phi*W-transported per-unit auxiliary channels to the frozen primary recurrence. Its finite autonomous development mean squared error (MSE) is 3.451830389554841e-8 versus parent 3.4709697955756664e-8, only a 0.5514% improvement; it fails the assigned <3.123872816e-8 primary gate and the <1e-8 stretch gate. Same-checkpoint teacher-forced MSE is 1.1469792562224471e-8.
