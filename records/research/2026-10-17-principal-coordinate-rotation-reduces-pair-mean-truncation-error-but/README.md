# Principal-coordinate rotation reduces pair-mean truncation error but costs more bill than predicted accuracy

2026-10-17T23:25:40Z · finding · rejected · measured

Rotating the current frame to principal coordinates reduced leading-256-coordinate pair-mean truncation error at every join. The required eigendecomposition and rotation exceeded the estimated final error benefit, while energy-based coordinate ordering had no effect.

Recorded measurement:

    Truncation error -13–17%; eigendecomposition 9n³ = .51 GF per join; +0.8% bill; estimated -0.2..-0.3% MSE.
