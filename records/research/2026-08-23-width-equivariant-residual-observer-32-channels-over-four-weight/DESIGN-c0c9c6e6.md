# Phase 2 estimator design: analytic backbone, learned residual, conditional tensors

Status: estimator design with provenance-complete, target-blind whestbench
0.16 / flopscope 0.12 resource receipts. Raw CLI output and 10 ms process-tree
RSS samples are retained and verified for the analytic host and the final CP
cap ladder. No Phase 2 target score is claimed here.

## Recommendation

The highest-probability first competitive estimator for width 1024 / depth 16
is a **correct full-covariance Hermite/Mehler order-2 chain plus a small
sequence-trained residual observer**. Add a capped CP third-order carrier only
if it improves the official compute-adjusted score. Do not begin by porting the
old rank-22 CP-TT host.

The reason is unusually direct: the public participant experiment reports
that the zero-fit order-2 analytic chain has only 0.12 times the MSE of
FLOP-matched Monte Carlo at this exact shape. The same ratio was 1.04 at the
old 256x32 shape. Wider affine mixing and half as many nonlinear resets are
exactly the regime in which low-order closure should accumulate less error.
This is strong ordering evidence, not a score; it must be replayed on the
Phase 2 data.

The primary contest metric is final-layer MSE multiplied by
`max(0.1, FLOPs / 2^41)`. Earlier layers are diagnostic. Training should use
the whole trajectory for stability but select models by held-out final-layer
compute-adjusted score.

## The candidate, component by component

### 1. Exact affine mean and full covariance

Carry a mean vector and a symmetric 1024x1024 covariance matrix. At every
layer, propagate both through the weight matrix using a single symmetry-aware
three-operand einsum. This is the reliable second-order spine; it replaces
the old covariance consumer and its repeated spectral repair.

Use float64 for the first accuracy run. The provenance-complete target-blind
subprocess receipt for the frozen order-10 source records 103,923,320,832
FLOPs, 4.7259% of the Phase 2 budget, 0.8820 seconds wall time, 0.0671 seconds
residual time, and 2,070,020,096 bytes peak sampled solution-descendant RSS.
Test float32 only as an accuracy and headroom alternative; it is unnecessary
for feasibility.

### 2. Correct Gaussian marginal ReLU map

For each neuron, compute the exact mean and variance of a rectified Gaussian.
These are exact one-dimensional identities conditional on the propagated
mean and variance. Restore the exact marginal variance on the covariance
diagonal after every off-diagonal approximation.

### 3. Correct Hermite/Mehler covariance, with order selected rather than assumed

The evidence-backed baseline is order 2:

- the order-1 term uses `s * Phi(a)`;
- the order-2 term uses `s * phi(a)` and is divided by `2!`;
- each term is an outer product multiplied entrywise by the corresponding
  power of the correlation matrix.

The general identity uses `1/r!`, not `1/(r!)^2`. An initial on-disk draft
made exactly that mistake: it divided each coefficient by `r!` and then
squared it. The concurrent analytic audit corrected the current prototype to
store orthonormal coefficients divided by `sqrt(r!)`. The current bound
verifier reports coefficient max absolute discrepancy `1.381e-7`, governed by
the offline Abramowitz-Stegun CDF approximation rather than the deployed
native CDF. Keep the normalization identity and a higher-accuracy SciPy-ndtr
parity reference as regression checks.

Run the validated order ladder `R = 1, 2, 4, 6, 10`. Every class remains below
4.73% of budget. A larger order is more accurate for a truly bivariate
Gaussian input, but the recursive state is only a closure approximation, so a
larger order is not guaranteed to improve the final mean. The current order-10
bivariate truncation bound is `3.763e-5` at `|rho| = 0.8`; this is an
approximation bound, not a measured network-mean error.

Every correctly normalized truncated term is PSD by the Schur product
theorem. Replacing the truncated diagonal by the exact variance adds the
nonnegative omitted Hermite tail. This gives a mathematical PSD construction
without an eigendecomposition. Do not entrywise clip a correlation matrix to
`+/-0.9999` and call the result certified PSD; arbitrary clipping does not
preserve PSD. In float64, use the genuine normalized covariance. If an
interior margin is required, use a PSD-preserving global shrink toward the
identity and record the induced bias.

### 4. Cheap calibration ladder before a recurrent model

Fit these in order, always using states generated by the deployable analytic
host:

1. per-layer scalar scale/offset calibration;
2. a shared local per-neuron residual MLP;
3. the recurrent observer below.

The first two establish whether Phase 2 closure bias is mostly local. They are
almost free to deploy and reduce the chance of fitting an unnecessary
recurrence.

### 5. A fresh Phase 2 recurrent residual observer

Reuse the useful structural idea from the Phase 1 32-channel observer, not its
checkpoint or normalization. A compact first candidate is:

- per-neuron analytic features: pre-activation standardized mean, log
  variance, Gaussian post-mean and variance, correlation/covariance row
  summaries, layer fraction, and local weight summaries;
- optional CP features: standardized diagonal K3 and normalized K21 row
  summaries;
- 32 recurrent channels split into four groups of eight;
- a shared 56 -> 80 -> 80 trunk and a bounded direct mean-residual head;
- identity/zero initialization of the residual head.

Train the observer through its full 16-layer recurrent rollout. Ground-truth
`all_layer_means` are the labels; there is no need to invent teacher hidden
states. Inputs at training time must come from the same autonomous analytic or
CP host used at deployment. A useful loss is final-layer MSE plus a smaller
all-layer trajectory loss, with model selection on network-balanced held-out
final-layer MSE and then the compute-adjusted score.

For the first learned candidate, leave the analytic mean/covariance carrier
unchanged and add the predicted residual only to the reported means. The
observer's hidden state is still trained end to end, but an imperfect
correction cannot destabilize the analytic carrier. Only test feedback into
the moment state if a teacher-substitution experiment shows that analytic
state drift, rather than the readout map, is the remaining floor. Any feedback
variant must be trained on its own autonomous rollouts, not isolated teacher
states.

The old raw `W`, `W^2`, `W^3`, `W^4` messages are not width-normalized. At
width 1024, higher raw powers collapse in scale and even powers carry a large
DC component. The preferred replacement is a weight-Hermite basis. If
`x = W / sqrt(2/n)`, use

`A_p = sqrt(2 / (n * p!)) * He_p(x)`, for `p = 1..4`,

then transport each eight-channel block through `A_p`. All four matrices have
zero-mean entries with the same variance under the known weight law. A lower
risk control is to keep raw powers but normalize power `p` by
`n^((p-1)/2) / sqrt(2^(p-1) * (2p-1)!!)`. Compare both on a network-level
holdout; never copy the Phase 1 message scales.

### 6. CP third-order carrier as the first tensor addition

If residual attribution points to non-Gaussian marginal bias, port only the
CP3 mechanism first:

- affine push of CP factors through each weight matrix;
- exact reads of diagonal K3 and K21 from the factors;
- the existing inherit/generate ReLU mechanism;
- energy-based truncation;
- a bounded Edgeworth K3 mean feature/readout;
- K21 supplied to the observer as features before it is allowed to modify
  covariance.

Do not reuse the old hand-tuned K4 synthesis constants or depth-8 bands. The
new depth is 16 and the entire state distribution has changed. Learn or
reselect any scalar K3/K4 readout jointly with the new analytic host.

The old cap 1024 meant four widths at n=256 and did not begin discarding until
the fifth generated block. It means only one width at n=1024 and begins
discarding on the next generated block. Preserving `cap / width = 4` would
require cap 4096, but that makes the dominant CP work roughly four times more
expensive relative to the new budget. Before target opening, freeze caps 512,
1024, and 1536 as the unconditional K3-only ladder. Cap 1792 was initially a
meter-only conditional candidate and has now been admitted before target
opening: the common driver proved it remains strictly under the 10% score
floor and passes the timing and measured-memory gates. Cap 2048 is excluded
from this ladder because its static total already exceeds the floor.

Keep the order-2 covariance PSD backbone independent at first. The Phase 1
K21 overlay required spectral repair because its additive covariance
correction could be indefinite. A third-order feature that improves the mean
does not need permission to destabilize covariance.

### 7. TT residual only after an attribution gate

The centered `TT3 - CP3` idea remains mathematically useful, especially its
exact delta-K21 overlay, but the old rank-22 deployment is the wrong Phase 2
starting point:

- a naive scaled rank-22 host is approximately 2.76T FLOPs, above the 2.199T
  budget;
- even rank 16 screens near 2.36T before a redesign;
- the future-weight action geometry alone scales to about 0.93T;
- the old 51-message, two-pass streamed provider creates many Python/remote
  dispatches under a 0.4-second residual-Python hard cap;
- the old per-layer spectral certificate is 323.1B FLOPs at the new shape.

If CP teacher substitution proves that discarded third-order structure is the
limiter, build a local, vectorized TT lane at ranks 8, 12, and 16. Replace
future-weight leverage with fixed target-blind sketches or local action probes,
batch provider messages into a few flopscope operations, retain the exact
delta-K21 read, and use the PSD Hermite covariance backbone instead of dense
repair. Rank 22 earns a test only after an actual 0.12 receipt leaves room.

### 8. Sampling is a comparator, not the opening architecture

Keep whitened QMC/Monte Carlo as a measured comparator and possible residual
control variate. The exact-shape 0.12 ratio says that spending the opening
budget on brute-force sampling is lower probability than fixing and fitting
the analytic chain. Hybridize only if equal-receipt validation reverses that
evidence.

Fixed-rank `depth * width^2 * rank` work grows by 8x, almost exactly the
8.085x budget increase. Dense cubic work grows by 30.97x, or 3.83x relative
to budget. A CP cap held fixed at 1024 is therefore almost budget-neutral;
preserving the old cap/width ratio makes it cubic-like and four times more
expensive relative to budget.

Score economics matter. All four K3-only caps have now been measured below
the 10% floor, so they receive the same 0.1 multiplier as the analytic host.
Their exact total shares are 6.206%, 7.677%, 9.050%, and 9.737% for caps 512,
1024, 1536, and 1792. Cap 1792 has 5,779,984,177 integer FLOPs of floor margin;
cap 2048 is statically above the floor. Full-K21 cap 1024 is also above the
floor at roughly 10.6%, so it needs about a 6% raw-MSE reduction to pay for
itself. The much larger legacy estimate bundled the Phase 1 consumer and must
not be treated as the incremental price of CP3 in the new host.

## Minimal implementation fork

The minimal scientific fork is the current full-covariance analytic prototype,
not the legacy CP-TT tree. Its coefficient normalization, unclipped
correlation, omitted diagonal tail, and native propagation of covariance
symmetry have passed both native and client/server checks. No explicit
`as_symmetric` call is required: the v0.12 symmetry tag survives the Schur
updates and earns the symmetry-aware n-ary einsum charge. Continue from that
corrected source:

1. bind the high-accuracy coefficient check and symmetric-einsum charge check as
   regression tests;
2. replace or explicitly qualify the low-accuracy Abramowitz-Stegun CDF in the
   offline reference before claiming strict float64 parity;
3. parameterize the order and freeze an R1/R2/R4/R6/R10 target-blind prediction
   ladder;
4. validate NumPy/flopscope parity on synthetic shapes;
5. preserve the completed flopscope 0.12 receipts, raw output, and RSS traces;
6. seal Phase 2 predictions before reading scores;
7. add scalar/local calibration, then the observer;
8. fork CP3 from the legacy carrier only after the analytic residual is known;
9. leave TT in a separate conditional experiment.

Keep the deploy estimator self-contained. In `predict`, use only flopscope
arrays and operations for numerical work, avoid Python per-neuron loops and
conversion of remote values to Python scalars, and batch all fixed-order loops.
The 14k-parameter observer is far below the 50 MiB package limit. MPS is useful
offline for feature generation and end-to-end recurrent training, but it is
not part of the submitted estimator.

## Data, training, and promotion protocol

- Split the 1000-network Phase 2 full set by network, never by neuron: for
  example 800 train / 100 validation / 100 locked test.
- Keep the disjoint mini-100 as a final rapid external check rather than a
  source of per-ablation tuning.
- Fit residuals against the public 1e9-sample means. These means are the
  supervision. High-sample moment rollouts are optional diagnostic teachers,
  not deployable inputs.
- Precompute analytic/CP states with a source hash. If feedback is tested,
  regenerate autonomous states during training; teacher-forced state features
  are not a valid final training distribution.
- Use MPS in batch size 1-2 with checkpointed layers. Monitor actual process
  memory and stop before pressure, rather than estimating safety from job
  count.
- Report final-layer raw MSE, all-layer diagnostic MSE, per-layer curves,
  flops, multiplier, wall time, residual time, and peak memory for every
  candidate.

A component is promoted only if it improves locked, network-balanced
compute-adjusted score and passes: finite `(16, 1024)` output, flops at or below
`2^41`, residual Python below 0.4 seconds (target 0.30 for margin), total wall
below 120 seconds, peak memory below 8 GiB, package below 50 MiB, and deterministic
replay.

## Decision tree

1. If corrected R2 is already near the target, fit only scalar/local residuals.
2. If a local residual cannot explain held-out error, add the sequence-trained
   observer.
3. If true-K3 substitution materially lowers the final-layer floor, add CP3 at
   cap 512 first, then meter cap 1024.
4. If true covariance substitution helps but K3 does not, improve the Hermite
   order or learn a PSD-preserving covariance map; do not add TT.
5. If CP-vs-true-third-order substitution isolates discarded K21/K3 structure,
   build the redesigned low-rank TT lane.
6. If equal-cost sampling beats the corrected analytic chain on the locked
   split, use it as a residual control variate; otherwise keep the estimator
   deterministic.

This ordering preserves the best Phase 1 insight—the mean depends on a coherent
joint state—while exploiting the decisive Phase 2 fact that the cheap analytic
state is now much more accurate.
