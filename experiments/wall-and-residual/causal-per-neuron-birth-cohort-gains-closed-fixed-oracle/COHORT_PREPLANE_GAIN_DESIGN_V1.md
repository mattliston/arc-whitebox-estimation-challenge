# Causal pre-plane birth-cohort transport-gain information test

September6,2026, Phase2. Bank329926 unchanged. This is distinct from the
closed inherited-distinct scalar-per-layer gain, the closed final-only32
cohort scalar features, the endpoint H x H x R-power plane regression,
and factor pruning. It retains every signed pair but gives each current
neuron a potentially different gain for each birth cohort. The templates
carry joint path information that endpoint-only functions of R lack.

One fixed TRAIN cell mini57/pre13. Before the CP-plane calculation freeze
the unchanged parent's pushed factors, signed weights, all13 birth cohort
boundaries, incoming recurrent state, and current preactivation geometry.
Construct104 fixed label-free features BEFORE the current plane/nonlinear
map/head:1, alpha, Gaussian gate/pdf, alpha*pdf, (alpha^2-1)*pdf,
log(sigma), CP-only diagonal skew, plus the existing message projection's
three16-channel W/W^2/W^3 incoming-state means and three corresponding
log(1+energy) groups. Do NOT multiply messages by the existing head's
normalized current x[:,5], which is unavailable at this causal boundary.
No current post-moment, current delta, current hidden state or target feature.
Use an input-only SVD to obtain the same span, cutoff1e-12*largest singular
value, orthonormal columns scaled by sqrt(n). This only preconditions the
one-cell oracle, not a cross-net parameter convention.

Run the otherwise unchanged parent through current pre13 and require all
previously frozen pre13 arrays and prefix bytes exactly. Preserve the
incoming feature/factor file BEFORE constructing any source/error fit.
Source templates are each cohort's signed CP K21 plane. Their sum must
match the original current active CP plane to roundoff; qualify that
roundoff <=.01 of the frozen true K21 residual RMS before fitting.

For a gain h_i,b=H_i theta_b, the exact first derivative of multiplying
cohort b's factor row i by1+t*h_i,b is

  Delta K21_ij = sum_b (2*h_i,b+h_j,b) K21_b,ij.

Set its diagonal to zero, keeping every marginal third cumulant fixed.
This corresponds to a diagonal-only tensor restoration, not a per-unit
moment supply or an inherited-distinct-only post restoration. All inactive
pair entries retain the current mask. Through the existing exact K21 pair
consumer, normalized S_b=K21_b/(sigma_i^2 sigma_j), define

  D_b,ij=2 L_ij S_b,ij + L_ji S_b,ji,
  Delta C=sum_b [diag(h_b)D_b + D_b^T diag(h_b)].

This new matrix-template span is not a row/age subset or a higher-rank retry
of the closed endpoint dictionary. Certify signed-cohort derivative,
diagonal restoration, exact covariance map, adjoint, score metric and small
dense ridge solve before any wide fitting.

One fixed zero-start PCG score-risk fit, ridge .001, tolerance1e-7,
max1000 iterations. Input-only normalization sc=sqrt(2 mean(sum_b D_b^2));
use B=DeltaC/sc, Y=target_cov/sc and the same certified risk action
M(E)=A E A+.5 tr(AE)A from bank post13 geometry. Loss is
<E,M(E)>/(2n^2)+.001||theta||^2/2. Diagonal preconditioner uses
2*H^2.T*(row_sums(D_b/sc)^2)/n^2+.001, where row_sums applies to
the ELEMENTWISE SQUARE of D (not the square of the row sum).

Require converged true normal residual AND risk/actual W14-response error
ratios both<=.50. Report gain extrema and <=.05 maximum-gain safety gate:
a large tangent fit is not assumed to be a finite physical improvement.
Also require exact finite(1+h) factor rescaling with current diagonal
restoration to meet both .50 consumer gates; no strength sweep if it does
not. No feature/ridge/age/rank/iteration sweep. A failed fixed pilot does
not authorize a cross-net fit or state write.
