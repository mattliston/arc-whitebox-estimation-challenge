# Masked learned covariance correction lowers charged work by 0.69% for 0.02% additional error

2026-10-02T05:48Z · experiment · adopted · measured

The learned covariance edge (layers 8-14, 1.20% of the bill) has raw output T_ij pdf_i gate_j with T bounded, so it was evaluated only on the layer's response rows x alive columns (about half the grid) and set to 0 elsewhere, with a 10-flop tanh stand-in on the kept block (EcutS). On the torch card the mask costs +0.016 to +0.026% of MSE while no edge at all costs +2.2 to +2.9%; natively about -0.69% of bill. Shipped in S38. The same row-mask idea does not carry to the plane read (+2.5% MSE for 5% of columns) or the mean-correction messages.

Recorded measurement:

    mask keeps 0.49 / 0.48 / 0.51 of the n x n grid (networks 35 / 100 / 651), MSE +0.026% / +0.021% / +0.016%; tighter mask +0.06-0.08%; no edge +2.2 to +2.9% (fresh-rank number +1.00%); native edge cut alone about -0.69% bill; edge at half strength -0.08%
