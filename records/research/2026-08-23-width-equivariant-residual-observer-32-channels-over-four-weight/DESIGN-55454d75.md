# Phase 2 inference-budget reallocation

Status: **TARGET-FREE DESIGN AUDIT — REAL COMBINED METERS REQUIRED**

This additive note asks where the inference budget is most likely to improve
the final-layer mean.  It reads only already-frozen aggregate scores and
target-blind meter receipts.  It opens no target value, fits no model, changes
no frozen source, and uses no Phase 1 weight, checkpoint, normalization, rank,
or fitted scalar.

## Outcome

The best balanced primary is:

```text
host                  CP3 cap 1536
recurrent channels    H = 128
message powers        P = 4 (32 channels per power)
cell width             C = 256
learned parameters     171,017
static observer FLOPs  10,985,525,112
conservative ceiling   13,182,630,135
combined ceiling      212,201,606,393
margin to score floor   7,700,719,162
```

The host-fidelity control is:

```text
host                  CP3 cap 1792
recurrent channels    H = 64
message powers        P = 4 (16 channels per power)
cell width             C = 96
learned parameters     30,377
static observer FLOPs   3,832,336,248
conservative ceiling    4,598,803,498
combined ceiling      218,721,144,876
margin to score floor   1,181,180,679
```

The control is deliberately tight and is ineligible unless its own common-
driver meter is at or below `219,902,325,555`.  Its deterministic fallback is
the already-metered CP1792, H32/P4/C64 recurrent scaffold at
`216,514,589,850` FLOPs, leaving `3,387,735,705`.

Each recurrent family retains its preregistered local/no-recurrence ablation;
that ablation is a causal control, not another host/capacity search.

## Why this allocation

The measured host ladder is very flat at the top:

| Host | Meter FLOPs | Final raw MSE | All-layer raw MSE | L2 raw MSE |
|---|---:|---:|---:|---:|
| Hermite 4 | 103,519,094,784 | 3.849300358689406e-6 | 2.1180294255017804e-6 | 1.5536452260972563e-7 |
| Hermite 10 | 103,923,320,832 | 3.849300547399477e-6 | 2.1180289543638134e-6 | 1.5536452694709453e-7 |
| CP512 | 136,462,170,114 | 3.799028043642153e-6 | 2.0302987318411863e-6 | 7.850484537840704e-8 |
| CP1024 | 168,812,139,522 | 3.762168087950475e-6 | 1.9742425590632073e-6 | 2.192582806672553e-8 |
| CP1536 | 199,018,976,258 | 3.7339069924135637e-6 | 1.936026483441147e-6 | 2.192582806672553e-8 |
| CP1792 | 214,122,341,378 | 3.722402415224689e-6 | 1.920413376561686e-6 | 2.192582806672553e-8 |

The often-quoted `103.923B` meter belongs to Hermite 10, not Hermite 4.
Their measured accuracies are effectively tied, so this bookkeeping
correction does not change the decision.

Moving from CP1792 to CP1536 gives up only `1.150457718887458e-8` final raw
MSE, or `0.3091%`, while freeing `15,103,365,120` FLOPs.  That buys the H128
observer with a robust pre-meter reserve.  CP1024 is the lowest cap that keeps
the high-cap L2 result and can support H256, but its extra capacity has more
optimization, training-time, and network-level overfit risk.  It remains the
best later challenger, not the first primary.

CP512 has ample compute but leaves L2 at `7.8505e-8`, much closer to the
`1e-7` scientific target, and carries a more truncated CP state.  Relative to
CP1792 it frees `77,660,171,264` host FLOPs and loses only `2.0585%` final raw
MSE, so CP512+T3 is a serious capacity challenger.  It is not the first
primary because output MSE does not measure the information retained in the
latent CP state: a 669,705-parameter observer cannot recreate columns already
discarded by cap 512.  T3 also has 55.6 times the T0 parameter count on only
688 independent fit networks, eight times T0 message-transport width, and no
H256 combined residual-time/RSS meter.  The 1024 neurons provide many loss
terms but are correlated within a network and are not 704,512 independent
network draws.  This makes optimization, network-level generalization, MPS
parity, and training turnaround materially riskier than CP1536+T2 despite its
large inference margin.

Hermite-only hosts have still more compute but do not supply the CP/K3
observer coordinates; constructing those coordinates would no longer be an
Hermite-only budget.

All hosts still require roughly a `97.3%` reduction in final MSE to cross
`1e-7`.  The tiny improvement from the last 256 CP columns is therefore less
valuable than a four-times-wider state that can learn a state-dependent error
map across depth.

## Exact generalized accounting

Let `n=1024`, `d=16`, `t=15`, `L=20`, recurrent channels `H`, message powers
`P`, cell width `C`, and cell input width `I=L+P+H`.  `H` must be divisible by
`P`.  The design retains all four normalized edge powers and their four local
column-sum features.  For a recurrent observer, the generalized V2 static
rows are:

```text
edge construction       d * 9 * n^2
message transport       t * n * H * (2*n - 1)
message RMS              t * P * (3*n*(H/P) + 2)
log special reserve      t * P * 64
local extraction         d * 16 * n^2
local standardization    2 * L * d * n
source/message gates     L*d*n + t*n*H
core I -> C              d*n*C*(2*I - 1)
core C -> C              d*n*C*(2*C - 1)
candidate + state gate   d*n*2*H*(2*C - 1)
mean head                d*n*(2*C - 1)
explicit biases          d*n*(2*C + 2*H + 1)
nonlinear reserve        d*n*(2*C + 3*H + 1)*64
hidden blend             d*n*H*6
decode/latch             d*n*67
```

Their sum exactly reproduces the frozen H32/P4/C64 static estimate
`2,056,671,096`.  The learned parameter count is

```text
C*(L+P+H) + C^2 + 2*H*C + 3*C + 2*H + 5 + P.
```

The local control uses the same cell inputs and constructs the same edge/local
features, but subtracts message transport, message RMS, and `t*n*H` message-
gate multiplies from the recurrent sum.  This reproduces the frozen local
estimate `1,048,563,456` at H32/P4/C64.

Static arithmetic is not an official meter.  The six target-free V3 combined
meters show a nearly fixed implementation tax:

| Host | H32 local overhead | local/static | H32 recurrent overhead | recurrent/static |
|---|---:|---:|---:|---:|
| CP512 | 1,381,231,038 | 1.3173 | 2,390,322,858 | 1.1622 |
| CP1536 | 1,382,785,452 | 1.3187 | 2,391,877,272 | 1.1630 |
| CP1792 | 1,383,156,652 | 1.3191 | 2,392,248,472 | 1.1632 |

For pre-meter admission only, this audit therefore uses

```text
conservative observer ceiling =
    max(static + 400,000,000, ceil(1.20 * static)).
```

This dominates every measured H32 local and recurrent overhead.  It is a
screen, not authority: every combined source still needs whestbench 0.16.0 /
flopscope 0.12.0 measurement under the official driver.

T3 has modest inference tensor sizes, but it makes recurrent training roughly
eight times heavier in its dominant message transport than T0 and raises the
parameter count to 669,705 on only 688 independent fit networks.  T2 is the
better first bet.  Inference RSS should remain host-dominated because even an
H256 hidden row is only 1 MiB and a C512 cell row is 2 MiB in float32, but this
does not replace a process-tree RSS measurement.  Vectorized dimensions should
mostly increase backend time rather than Python residual time; the 0.4-second
residual and 8-GiB gates remain mandatory.

If the CP1536+T2 combined source fails its actual common-driver meter, the one
predeclared resource fallback is CP1536+T0 H32/P4/C64.  Its target-free V3
combined meter already passed at `201,410,853,530`, with `18,491,472,025`
FLOPs of floor margin, descendant RSS `2,411,364,352` bytes, residual time
`0.1503887456` seconds, and wall time `1.472641375` seconds.  This fallback
must be frozen before target release; a meter failure does not authorize an
after-target capacity search.

## Accuracy and custody invariants

- Layer 1 correction remains structurally zero for every parameter value.
- Layer 2 remains eligible only when its raw MSE does not exceed the frozen
  host on selection, audit, and lockbox.  Observer output never feeds the host,
  so this gate cannot change the layer-16 analytic trajectory.
- Fit uses only hashed positions `12:700`; selection only `712:800`; audit and
  lockbox remain sealed one-use roles.  The 24 teacher-attribution rows remain
  retired.
- Capacity, source, meter, initialization, local/recurrent arms, and fallback
  must be frozen before any role-target release.
- No Phase 1 learned tensor or fitted scalar is admissible.
- A failed meter, parity, L2, promotion, resource, or custody gate falls back
  to the untouched host; it does not authorize another capacity sweep.

The objective `raw L16 MSE < 1e-7` is a scientific target, not evidence that
any unfit design has reached it.
