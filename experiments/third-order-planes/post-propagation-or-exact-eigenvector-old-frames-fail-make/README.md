# Post-propagation or exact-eigenvector old frames fail to make rank 320 worthwhile

2026-09-23T02:59Z · experiment · rejected · measured

Picking the shared old-tier frame in pre-activation space after the push, or from exact top-r eigenvectors instead of the one-pass sketch, roughly halves the loss of a lower rank but does not remove it: the best rank-320 frame is +3.9% raw (2-net mean) for a native -6% util, and an exact or power-iterated frame costs 1-1.5 units per join layer (+5-8% bill), so the frame line is closed.

Recorded measurement:

    final-MSE ratio vs bank rank 384 (r35 / r100): sketch post 384 1.000/1.000, 320 1.094/1.145, 256 1.384/1.428; sketch pre 384 1.012/0.993, 320 1.086/1.073, 256 1.288/1.155; exact eig post 384 1.015/0.968, 320 1.043/1.035; exact eig pre 384 1.014/0.978, 320 1.064/1.013, 256 1.178/1.242
