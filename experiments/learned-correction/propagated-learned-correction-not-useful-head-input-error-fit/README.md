# Propagated learned correction is not a useful head input: error-fit R^2 <= 0.024

2026-10-10T09:29Z · experiment · rejected · measured

The moment-closure estimator's pre-activation mean error at layer l+1 regressed on the previous layer's head correction pushed through the weights has slopes of random sign, so the carried error is not a calibration error of the correction.

Recorded measurement:

    slopes -0.70..+0.53 across networks and layers 8->9, 11->12, 13->14, 14->15, R^2 <= 0.024
