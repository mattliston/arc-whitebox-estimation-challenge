# Old-plane regression from 14 live matrices explains only 53–69% of in-sample variance

2026-09-22T20:55Z · experiment · rejected · measured

An in-sample regression of the old plane on 14 live matrices, including a memoryless transport of the previous old plane, explains at most 69% of it (27-60% without the transport feature), far from the ~0.99 the eps law requires, so carrying the old content as a regenerated function of the live state is dead.
