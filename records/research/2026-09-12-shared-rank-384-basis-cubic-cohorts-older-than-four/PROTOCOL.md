## Representation, source action, and ownership

Let F have shape384 by R for the old signed columns and let Q be the common
current-coordinate basis. Store the weighted Gram core S = F D F^T. The
state is local to one `_predict_binary` invocation; no basis, factors,
Gram core, data-dependent cache, or prior-call state survives prediction.
The original full p post-gating remains allocated and paid. Old p columns
are not used for their dense linear push; keeping them does not create a
claimed scan, storage, or runtime saving.

At a join, gather only the exact previous_alive rows of the dense joiner J
and the gated old basis Qp. For a = number of those rows, use Omega equal
to `w32[previous, :384]`, the already paid current physical weight block.
There is no RNG, external seed array, data lookup, offline feature bank, or
hidden eigenspace acquisition. Form

    Y = J Djoin (J^T Omega) + Qp S (Qp^T Omega)
    Qnew = reduced_QR(Y).Q
    Fjoin = Qnew^T J
    T = Qnew^T Qp
    Fnew = concatenate(T F, Fjoin)
    Snew = T S T^T + Fjoin Djoin Fjoin^T.

The old terms are absent at the first join. This is ONE range-finder pass,
not an eigendecomposition, power sweep, or adaptive retained-energy rule.
If a<384, the fixed constructor fails; it does not silently lower rank.
QR, factor and Gram outputs are FP32 and checked finite by paid operations.
No symmetrization, eigenvalue floor, covariance repair, or fallback is added.

Push U = W[previous,:]^T Qnew (or the prior gated active basis at L15).
Reconstruct X = U F for ALL1024 rows. Read only the current response-by-alive
rectangle through

    old_plane = ((X_response * X_response) (F diag(lambda))^T) U_alive^T.

There is one trailing old-basis product, not one per cohort. The young
rectangle uses the exact original `_mm(left*left, (right*lambda).T)`.
Their FP32 sum is widened at the same original point. The current all-row
FP64 diagonal cubic read and omitted-radial calculation are byte-unchanged
source and still consume the reconstructed complete pp bank. Their FLOPs
are not removed from the complete price.

Projection changes the inherited tensor BEFORE its current linear read.
There is deliberately NO extra incumbent-plane-exact repair at the join.
The original nonlinear star construction and SINGLE original BD stored-pair
repair remain untouched. This omission is an explicit approximation choice,
not a zero-cost claim that the original plane is preserved. Reconstructed
FP32 X and factored FP32 read also differ by normal reassociation/rounding;
the formula is an exact real-arithmetic contraction of the factorized
representation, not byte identity to the old signed bank.

P/NODE remains live on the altered trajectory with its original parameters.
No head refit, frozen feature replay, optimizer, gradient qualification or
native-AD claim is authorized. Domain checks may fail and selector geometry
may change. There is no raw-accuracy benefit forecast.

## Legal existing-kernel compilation

Every new matrix product uses the current `_mm` and its existing arena.
Only J^T Omega can have an output row axis above1024. Its at-most2048 rows
are split into disjoint at-most1024-row products, then concatenated in
order with the ordinary counted FNP operation. This avoids passing an
oversized m into the parent's fixed-size arena. The parent already owns
all contracted/output-axis8192 tiling. There is no new Strassen depth,
shape dispatcher, padding policy, scratch backing array, or arena alias.

No out parameter aliases a live matrix input. Each `_mm` returns its own
result; only its internally managed scratch is shared serially. Joins finish
before basis push/reconstruction/read. Temporary arrays are ordinary paid
FNP outputs; no unmetered NumPy/Torch helper or borrowed profiler operation
does mathematical work. The helper fragment has only function definitions
and a docstring at module scope, hence no import-time array construction.
