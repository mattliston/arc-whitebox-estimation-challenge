# Tilted cubic mean-response compression metric: exact but no affordable constructor (36.27 GF extra on old geometry)

2026-09-08T07:19Z · finding · rejected · derived

For a symmetric third-tensor error T and a fresh Gaussian query w the risk E[T(w,w,w)^2] = tau^6 (6 ||T||_F^2 + 9 ||trace T||^2), which for trace-free (all-distinct) error is exactly the already-closed whole-pair kernel objective; a local mean-response metric R(T) weighted by the deployed derivative -alpha phi(alpha) delta_k3 / (6 v) was derived in closed form, but acquiring the needed slice T(u, ., .) requires the full physical CP plane (the third tensor carried as a sum of weighted rank-one cubes lambda_r p_r^3) that the response-masked plane does not supply. No cheap dictionary or core with retained value was found and no compression experiment was admitted.

Recorded measurement:

    additional ordinary FP32 product subtotal on the OLD post7 geometry a896, M13376, K1024: a*a*(2M-1) + a*K*(2a-1) + 7*K*K*(2a-1) = 36,265,377,792 F, reducing an old 88.711B modeled saving to 52.446B before extras; the closed whole-pair kernel arm had 19.025% complete cost saving and 4.910x worse adjusted error
