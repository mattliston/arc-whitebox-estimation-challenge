# Phase 2 migration reused cumulant identities and carrier formulas while discarding old fitted parameters

2026-08-23T17:17Z · decision · adopted · derived

A migration matrix separated reusable mathematics from stale empirical choices: universal cumulant and ReLU identities, the CP3 third-cumulant factor carrier with its K21 plane overlay, the correlation-interior PSD rule and the local Edgeworth mean link carry over; the rank-22 TT3 residual, the 32-channel learned observer checkpoint, the A161-A166 learned-feedback ladder, every Phase 1 score, FLOP receipt and public/train split do not. The ordered Phase 2 lanes were: pin authority and meter, rebase the meter under flopscope 0.12, run a fresh analytic hierarchy (diagonal Gaussian, order-2 Hermite/Mehler, CP3, CP3 plus TT3), attribute the bottleneck with teacher substitutions, retrain a learned correction only for the residual that remains, keep whitening/QMC as a measured comparator, and promote only sealed target-blind predictions.
