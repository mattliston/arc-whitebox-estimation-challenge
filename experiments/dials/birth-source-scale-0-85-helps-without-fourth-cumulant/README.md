# Birth-source scale 0.85 helps without fourth-cumulant shifts and harms with them

2026-10-02T04:18Z · experiment · rejected · measured

The b-carrier source scaled by 0.85 gave -0.576% alone and -0.808% with run L's parameters on 97 held-out networks of the card without the fourth-order column shift, but on the S37 card with the shift on it reads +0.23%: the column shift took that role (both act on the same fourth-order feed). The carried-b scale (bscale) is at its optimum: up by 0.01 / 0.02 / 0.03 is +0.48 / +1.06 / +1.81% on fresh ranks and down is worse too, although network 35 alone had said -1.0% for +0.01. Forward scans of single dials find at most 0.3%.

Recorded measurement:

    97 held-out: run L start -0.234% (se 0.112), + bsrc 0.85 -0.808% (se 0.210, 68 of 97), bsrc alone -0.576% (se 0.155, 63 of 97); S37 card: bsrc 0.85 +0.23% (se 0.36, 15 ranks); bscale +0.01 / +0.02 / +0.03: +0.48% (se 0.25) / +1.06% (se 0.31) / +1.81% (se 0.58), 0 of 6 better; bscale -0.01 / -0.02 / -0.04 (16 nets): +0.26 / +0.98 / +2.09%; recentring -0.1 / -0.2: -0.01 / +0.09%; K4L 0.75 vs 1: -0.34% (se 0.16, 10 of 15)
