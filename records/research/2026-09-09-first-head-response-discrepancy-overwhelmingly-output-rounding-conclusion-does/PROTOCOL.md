## Fixed inputs and decomposition

Use exactly ranks35/100, all five existing P cases null,+.025,-.025,+.05,
-.05, and the original saved cotangents. Primary comparison is native N
versus CPU. Also report the already-captured native L/R controls as clearly
secondary diagnostics, without selecting or combining them.

Authenticate CB's native_n_v1, cpu_v1, native_controls_v1 and judgment_v1
result/completion pairs and every recorded source/input/artifact hash before
numeric array reads. Authenticate original CO probe result/completion and
the exact scalar/served helper source. No moment-truth or weight arrays are
decoded. Only prediction, host1, delta1 and original cotangent arrays load.

For each endpoint, reconstruct in FP64

    z = max(host1 + float64(delta1), 0).

Require float32(z) to equal the saved served row1 byte-for-byte. Native
delta1 is stored FP32; CPU delta1 FP64. Never round the latter prematurely.
Require all five pre-head hosts and served layer0 bytes within each arm to
be identical. Evaluate the original scalar on each individual served
endpoint with only row1 present in a16x1024 zero scaffold, matching the
original CB judge exactly. Reproduce every saved individual scalar and
served secant exactly before analyzing the new decomposition.

For z use the SAME linear FP64 cotangent reduction and scaffold, but omit
the FP32 return conversion. Calling the original served helper on z would
erase this distinction and is explicitly forbidden. Compare direct linear
reduction of served FP32 values against the actual original helper exactly.

For each arm and each original h define

    r_y = (y_plus - y_minus)/(2*h),
    r_z = (z_plus - z_minus)/(2*h), q = r_y-r_z.

For N versus CPU, and secondarily L/R, report D_y=r_y(N)-r_y(other),
D_z=r_z(N)-r_z(other), Q=q(N)-q(other). Report all vector norms, signed
scalar values, signed projections, and verify D_y=D_z+Q. Scalar operations
use differences of the individual endpoint reductions in the original
order, not a newly chosen cotangent or a clamped signed response.
Require decomposition scalar/vector residuals <=1e-12 absolute and compare
saved original discrepancies/secants exactly. A zero denominator stays
inconclusive; no amplified near-zero ratio is promoted to evidence.

## Interpretation fixed before execution

For the PRIMARY N/CPU comparison only, label return rounding locally
dominant if, on EVERY rank/amplitude, both norm(D_z)/norm(D_y)<=.25 and
abs(scalar(D_z))/abs(scalar(D_y))<=.25, with norm(D_y)>1e-10 and
abs(scalar(D_y))>1e-10. Always report all four cases regardless of this
diagnostic classification. This threshold governs wording, not advancement.
No post-hoc threshold, amplitude, arm, scalar or case choice.

Regardless of classification, the original whole-card5% scalar gate stays
FAILED. CB has only layer1 unrounded captures; these data cannot diagnose
