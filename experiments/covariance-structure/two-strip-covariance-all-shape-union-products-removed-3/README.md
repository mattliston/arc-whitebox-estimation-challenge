# Two-strip covariance with all-shape union products removed 3,653 requests for 0.42% local bill

2026-10-17T19:03:05Z · experiment · adopted · measured

The two-strip covariance sandwich was combined with union push products to provide a lower-request submission. All-shape union retained essentially the same bill as the restricted union while adding request cushion, but the platform charged a larger premium than the local comparison.

Recorded measurement:

    33 store ranks with restricted union: bill +0.454% (SE .027), requests -3,252; all-shape 8-rank bill +0.42%, requests -3,653, raw -0.04% (SE .15); platform utilization +0.76%.
